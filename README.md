## How to use this. 

1. Create a feature branch: `git checkout -b feature/description`
2. When making a new branch, work in your own files that you've named accordingly, I don't want to deal with actual merges
3. Make changes and commit frequently: `git add . && git commit -m "type: message"`
4. Push to GitHub: `git push -u origin feature/description`
